# SDX v0.1.0

SDX 的第一个版本，从开源项目 [cc-haha](https://github.com/NanmiCoder/cc-haha) v0.6.5 分叉而来。

本版本只做身份层的改名和工程基线搭建，**功能与上游 v0.6.5 一致**。

## 变更

**品牌与标识**

- 产品名 `Claude Code Haha` → `SDX`
- Bundle ID / Windows AppUserModelID `com.claude-code-haha.desktop` → `com.sdx.desktop`，
  sidecar 签名标识同步为 `com.sdx.desktop.sidecar`（与 macOS 辅助进程的签名链校验保持一致）
- 安装包命名 `Claude-Code-Haha-${version}-*` → `SDX-${version}-*`
- CLI 可执行文件 `claude-haha` → `sdx`；`claude-haha` 保留为别名，老的 PATH shim 仍可用
- npm 包名 `claude-code-local` / `claude-code-desktop` → `sdx` / `sdx-desktop`

**工程**

- 版本线从上游的 0.6.5 切到 SDX 自己的 0.1.0
- 上游 v0.1.0 – v0.6.5 的发版说明归档到 `release-notes/upstream/`
- 补 `LICENSE`（MIT，保留上游版权）与 `NOTICE.md`（分叉来源、已改与未改的标识符清单）
- `packageManager` 对齐实际使用的 bun 版本

## 升级提示

- macOS / Windows 用户数据目录随产品名变化，**从 cc-haha 升级到 SDX 不会自动继承本地配置**，
  首次启动相当于全新安装。
- 如果之前用 `claude-haha` 往 shell 配置里注入过 PATH，旧的 `# >>> Claude Code Haha PATH >>>`
  标记块不会被新版本清理，需要手动删掉。

## 已知限制

- `CC_HAHA_*` 环境变量名尚未改名，仍需按原名设置。
- macOS Computer Use 辅助进程仍名为 `cc-haha-computer-use`（改名会重置系统授权，留到后续版本）。
- 自动更新、代码签名仍指向上游配置，SDX 尚未接入自己的发布渠道。
